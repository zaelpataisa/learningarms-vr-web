## ⚙️ Technical Requirements

* Meta Quest 2 or Meta Quest 3.
* Hand tracking enabled (optional but recommended).

## 📥 Installation Guide (Meta Quest)

Since this application is not on the official Meta Store, you need to "sideload" the APK:

1. Enable **Developer Mode** on your Meta Quest via the Meta Horizon mobile app.
2. Download the `LearningArms_v1.0_main.apk` file from the [Releases](https://github.com/zaelpataisa/learningarms-vr-web/releases/tag/v1.0) section.
3. Connect your Quest to your PC via USB.
4. Use [SideQuest](https://sidequestvr.com/setup-howto) or the Meta Quest Developer Hub (MQDH) to install the `.apk` file into your headset.
5. In your Quest, go to the App Library, filter by "Unknown Sources", and launch **LearnArms VR**.
